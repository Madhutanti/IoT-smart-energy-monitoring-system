# ⚡ Smart Energy Meter using ESP32

## About the Project
This is an IoT-based Smart Energy Monitoring System built using ESP32. It monitors voltage and current, calculates power and energy consumption, and estimates electricity costs.

The system also detects power overloads and alerts users through an LED and buzzer.

## Features
- Real-time voltage and current monitoring.
- Power and energy calculation.
- Electricity cost estimation.
- Overload detection and alerts.
- IoT-based monitoring.

## Components Used
- ESP32
- 2 Potentiometers
- LED
- Buzzer

## Technologies
- Embedded C
- ESP32
- Wokwi Simulator
- Firebase
